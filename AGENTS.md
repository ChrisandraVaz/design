# Responsive UI requirements

All new or changed UI must work on phones, tablets, and desktop. Preserve the user's authored desktop composition and original design assets.

- Use the shared responsive contract in `src/app/responsive.css`: fluid outer gutters, section spacing, bounded media, readable typography, and content-driven stacking.
- The portfolio uses a normal grid at widths up to 1100px and a draggable canvas above 1100px. Keep the matching boundary in `src/hooks/useCanvasDrag.ts` synchronized. Resizing clears drag offsets.
- The user selected layout 02, “Time at the edge,” in `public/layout-options/layouts.json`. Preserve that 1250px composition with the approved wider Queue and Watch and larger Shader and Metallic cards on desktop load/reset, including short, wide windows. It places Send to Agent at the top left, Font Context beside it in the first row, and Apple Watch directly beneath Font Context. Relative Time starts at the top right. Relative Time must stay outside the column beneath Send to Agent. The Canvas fills the shared page frame by width; lower cards can scroll. Desktop scale is computed in CSS before hydration. Hover must not resize neighboring cards; Reset animates back to these same positions.
- Do not fix overflow by clipping the entire page. Fix intrinsic widths, flex/grid minimums, media sizing, or give intentionally wide tables their own scrolling region.
- Keep navigation available on mobile and primary controls at least 44px high. Preserve keyboard focus, native touch scrolling, and reduced-motion support.
- For layout or interaction changes, run `npm run test:responsive`. The suite discovers case-study routes and covers 320, 390, 600, 768, 1024, 1440, and 1920px, plus touch, drag/resize, navigation, and reduced motion. Add behavior checks when adding interactions.
- Inspect the generated Home and Trace screenshots; passing width assertions does not prove visual quality. Run the build for structural/code changes.
- Reference and writing decisions are recorded in `docs/portfolio-design-principles.md`.
